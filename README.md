### About me

I've been writing code since 2013. Started in school, self-taught, with C#. By 2018 I had moved mostly to web, but I still build desktop and mobile apps. These days I head an application development department, and outside of that I take on client projects: CRMs, ERP modules, cost calculation systems, bank integrations, websites and Telegram Mini Apps.

I usually own a project from spec to production: I work out the requirements with the client, design the database, write the backend and frontend, and deploy to my own servers. For bigger projects I bring in my team. I'm not tied to one stack and pick tools to fit the job.

Most of my work is commercial and lives in private repositories. What you see here are my own public projects.
